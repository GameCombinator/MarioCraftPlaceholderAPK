# MarioCraft Placeholder APK project

This is a minimal Android Studio project for a placeholder app using Android WebView.

## Build an APK
1. Upload the contents of this folder to a GitHub repository.
2. Open the repository's Actions tab and run **Build MarioCraft Placeholder APK**.
3. Download the `MarioCraftPlaceholder-debug-apk` artifact from the completed workflow run.

You can also open this folder in Android Studio and select Build > Build APK(s).

## Note
This is a placeholder app, not the MarioCraft game itself. Its button opens the repository page in WebView. It does not compile or run the native project from that repository.
